# AGENTS.md

## О проекте
Небольшой инструмент для построения/обновления цепочки сертификатов PKI с использованием CryptoPro CSP (утилита `certmgr`). Скрипт `get_chain.sh` рекурсивно обходит цепочку от стартового сертификата: извлекает CRL Distribution Points и Authority Information Access (AIA), скачивает недостающие CRL/сертификаты УЦ и рекурсивно обрабатывает родительские сертификаты, определяя корневой (самоподписанный).

## Структура репозитория
- `get_chain.sh` — основной скрипт загрузки цепочки
- `secrets/` — исходные сертификаты (игнорируется git'ом)
- `downloaded_chain/` — скачанные CRL и сертификаты УЦ (игнорируется git'ом)
- `.gitignore` — исключает `secrets/` и `downloaded_chain/`

## Требования окружения
- ОС Linux
- Установленный CryptoPro CSP с утилитой `certmgr` (по умолчанию ожидается по пути `/opt/cprocsp/bin/amd64/certmgr`)
- `curl`, `logger` (обычно доступны в стандартном окружении)
- Доступ к URL из расширений сертификата (CRL DP, AIA) из сети

## Конфигурация
Скрипт использует жёстко заданные пути в блоке `КОНФИГУРАЦИЯ`:
- `PROJECT_DIR` — корень проекта
- `OUTPUT_DIR` — каталог для скачивания (`$PROJECT_DIR/downloaded_chain`)
- `START_CERT` — стартовый сертификат (`$PROJECT_DIR/secrets/my_cert.cer`)
- Пути утилит `CERTMGR`, `CURL`, `LOGGER`

Перед запуском нужно поправить пути под текущее окружение или сделать их настраиваемыми.

## Запуск
```bash
chmod +x get_chain.sh
./get_chain.sh
```
Логи дублируются в консоль и в syslog с тегом `cpro_chain_downloader`.

## Особенности работы
- Парсит вывод `certmgr -list -file` на русском языке (ищет строки `URL списка отзыва`, `URL сертификата УЦ`, `Субъект`, `Издатель`)
- Если CRL/родительский сертификат уже существует в `OUTPUT_DIR` — пропускает скачивание
- Рекурсивный обход по AIA
- Определение корневого УЦ по совпадению `Subject == Issuer`

## Рекомендации для агентов
- Не коммитить содержимое `secrets/` и `downloaded_chain/` (уже в `.gitignore`)
- При правках `get_chain.sh` сохранять совместимость с bash, не использовать `cd` вместо `workdir`
- Учитывать, что `certmgr` специфичен для CryptoPro CSP
- При изменении парсинга учитывать возможные переводы/форматы вывода
